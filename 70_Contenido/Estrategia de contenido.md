# 📣 Estrategia de contenido

> Regla de oro: **no se crea contenido desde cero**. Todo nace de una nota de `20_Conocimiento`,
> de una lección del curso o de un error real de una sesión (anonimizado).

## Audiencias
| Audiencia | Qué quiere | A dónde la llevamos |
|---|---|---|
| `tutores` (principal) | Empezar a enseñar, conseguir alumnos, tener método | Skool → Curso de Nuevos Tutores |
| `estudiantes_en` | Hablar español de verdad, sin aburrirse | Clases particulares → futuro curso EN |
| `estudiantes_general` | Entender español, curiosidades | Seguidores → lista de email |

## Pilares (valores de `pilar` en la [[Taxonomia]])
| Pilar | Audiencia | Ejemplo |
|---|---|---|
| `ensenar_espanol` | tutores | "Cómo explicar ser/estar en 2 minutos" |
| `negocio_tutor` | tutores | "Cuánto cobrar en tu primera clase" |
| `herramientas_ia` | tutores | "Creo una ficha de clase en 5 min con NotebookLM" |
| `gramatica_facil` | estudiantes | "El subjuntivo con una sola regla" |
| `errores_comunes` | estudiantes | "Nunca digas *estoy embarazada* si…" |
| `cultura` | ambos | Expresiones, variedades, costumbres |
| `historias` | ambos | Casos de alumnos (anónimos), tu camino como profe |

## La cascada: 1 pieza pilar → 8-10 piezas

```
            [Nota de concepto / Lección de curso]
                            │
                 PIEZA PILAR (larga)
       Lección Skool  ·  Vídeo YouTube  ·  Live
                            │
   ┌──────────┬──────────┬──┴───────┬───────────┬────────────┐
 Reel/TikTok  Carrusel   Post Skool  Hilo/       Email       Lead magnet
 /Short (x3)  IG/LinkedIn /Facebook  Threads/X   newsletter  PDF (NotebookLM)
                                                              HTML (Claude)
                            │
                       Flashcards
```

## Matriz plataforma × formato

| Plataforma | Formatos | Rol |
|---|---|---|
| **Skool** | `leccion_skool`, `post`, `live` | Casa: comunidad y curso (convertir) |
| **YouTube** | `video_largo` | Pieza pilar, búsqueda a largo plazo |
| **YouTube Shorts / TikTok / Instagram** | `reel` | Alcance y descubrimiento |
| **Instagram / LinkedIn** | `carrusel`, `post`, `historia` | Guardados, autoridad (LinkedIn → tutores) |
| **Facebook** | `post`, `reel` | Grupos de profes y estudiantes |
| **Threads / X** | `hilo` | Ideas rápidas, tests de ganchos |
| **Pinterest** | `pdf` como pin | Tráfico a lead magnets |
| **Newsletter** | `email` | Relación directa, ventas |

## Cadencia semanal (propuesta inicial, ajustable)
| Día | Pieza |
|---|---|
| Lunes | 1 pieza pilar (lección Skool o vídeo largo) |
| Mar–Vie | 1 reel/short al día, repartido en TikTok + Reels + Shorts |
| Miércoles | 1 carrusel (IG + LinkedIn) |
| Jueves | Post de comunidad en Skool (pregunta o reto) |
| Viernes | Email semanal |
| Mensual | 1 lead magnet (PDF/HTML) + 1 live |

## Herramientas
- **NotebookLM:** subir fuentes de `10_Fuentes` + notas de concepto → guías PDF, resúmenes de audio, cuestionarios.
- **Claude:** guiones, carruseles, materiales HTML interactivos (ejercicios, tarjetas) a partir de las notas.
- **Obsidian Bases:** `99_Sistema/Bases/Contenido.base` = pipeline y calendario.

## Flujo
1. Idea → `70_Contenido/Ideas/` (plantilla **Idea**)
2. Producción → `70_Contenido/Produccion/` (plantilla **Pieza de contenido**, una nota por pieza)
3. Publicado → mover a `70_Contenido/Publicado/` con `url` y resultados
4. Las piezas que funcionan → `estado: reciclar` para reutilizarlas en otro formato o plataforma
