# Segundo Cerebro de Español 🧠🇪🇸

Bóveda de Obsidian para organizar todo el conocimiento de enseñanza de español y convertirlo en:
**clases**, el **Curso de Nuevos Tutores** (producto principal), **contenido para redes y Skool**,
**flashcards** y futuros **cursos para angloparlantes (A0–B2)**.

**Método Misiones 80/20** (situaciones con goals medibles) organizado en un **árbol de habilidades A0→B2**: cada alumno
tiene su propio árbol, que se desbloquea a medida que avanza y le muestra la ruta hacia su meta.

- 🤝 **[HANDSHAKE.md](HANDSHAKE.md)**: el plan, las decisiones y las fases. Empieza por aquí.
- 🏠 **[Inicio.md](Inicio.md)**: panel principal dentro de Obsidian.
- 🤖 **[CLAUDE.md](CLAUDE.md)**: reglas que sigue Claude al trabajar en la bóveda.

## Cómo empezar
1. Abre esta carpeta como bóveda en Obsidian (o copia las carpetas a tu bóveda actual).
2. Activa los plugins núcleo **Bases**, **Canvas** y **Plantillas** (la carpeta de plantillas ya está configurada).
3. Ejecuta `python 99_Sistema/scripts/arbol.py` y abre `60_Estudiantes/Arboles/Demo Emma.html`.
4. Sigue el plan paso a paso de `HANDSHAKE.md` §8.

> 🔒 Los datos de alumnos y los PDF/epub no se suben al repositorio (ver `.gitignore`).
