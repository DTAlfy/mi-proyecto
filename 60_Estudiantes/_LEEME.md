# 60 Estudiantes — 🔒 privado
- `Alumnos/`: una ficha por alumno (plantilla *Alumno*).
- `Sesiones/`: una nota por clase (plantilla *Sesión*), nombre `AAAA-MM-DD Nombre`.
- `Evaluaciones/`: cada 4-6 clases (plantilla *Evaluación*).

Estas notas **no se suben** al repositorio (ver `.gitignore`): se quedan solo en tu PC.
Para migrar el Google Sheet: expórtalo como CSV a `10_Fuentes/Sheets/` y pide a Claude que cree las fichas.
